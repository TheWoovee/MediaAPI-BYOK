# MediaAPI-BYOK

A bring-your-own-keys media studio for `thewoovee.com`: generate and edit images and videos through
cloud providers (xAI, fal.ai, Replicate, Hugging Face, RunPod, Seedance…) and through your own local
servers (ComfyUI, A1111/Forge), from any device. Keys stay in the browser; a small Cloudflare Worker
proxies provider calls and serves the app.

Start with the plan: [docs/PLAN.md](docs/PLAN.md) — requirements analysis, open questions,
architecture, phased implementation, and the Cloudflare + GitHub deployment plan.
